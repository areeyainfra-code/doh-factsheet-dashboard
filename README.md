# Factsheet Data Readiness

Dashboard ความพร้อมของข้อมูลสำหรับ Factsheet FS1–FS12 ของกรมทางหลวง (ข้อมูล ณ 22 พ.ย. 2569)

- เปิดหน้า `index.html` เพื่อดู Dashboard (สลับแท็บ ภาพรวม / รายปี / ข้อมูลขัดแย้ง / FS1–FS12 ได้)
- ไฟล์ `DOH_Factsheet_Dashboard_2569-11-22.pdf` คือเนื้อหาชุดเดียวกันทุกแท็บในรูปแบบ PDF
- กราฟใช้ไลบรารี d3 จาก cdnjs.cloudflare.com ต้องต่ออินเทอร์เน็ตจึงจะเห็นกราฟ

## ข้อควรระวัง

- ตัวเลขสรุปจากไฟล์ที่เปิดอ่านได้ ยังไม่ได้ตรวจซ้ำกับต้นฉบับของหน่วยงานทุกค่า
- รายการในแท็บ "ข้อมูลขัดแย้ง" ยังรอเจ้าของข้อมูลยืนยัน
- ชื่อหน่วยงานที่ควรขอข้อมูลเป็นข้อเสนอ ควรยืนยันก่อนทำหนังสือขอข้อมูล
